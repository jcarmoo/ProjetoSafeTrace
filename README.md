# ProjetoSafeTrace
O SafeTrace é uma proposta de segurança urbana para estudantes universitários em deslocamentos fora do campus, como sair da faculdade à noite, caminhar até o ponto de ônibus ou voltar para casa sozinho. A solução integra aplicativo e pulseira, com recursos de prevenção, conexão entre alunos e acionamento de emergência.
